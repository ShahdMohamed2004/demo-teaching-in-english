# Vehicle Adventure — English Learning Lab

A focused, interactive English lesson for young learners. The experience teaches vehicle vocabulary, simple actions, and short sentences through seven activities: Meet, Match, Listen, Can it?, Four corners, Draw & guess, and Final challenge.

## Design direction

The interface uses one clear learning focus at a time. The activity stepper shows progress without competing with the current task, while teacher controls stay collapsed until they are needed. The page is dependency-free and runs as a static GitHub Pages site.

## Local preview

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173/` in a modern browser.
